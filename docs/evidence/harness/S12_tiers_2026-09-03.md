## 2. The frozen promotion rule

`docs/evidence/harness/FACTORY_TIERS_SPEC_2026-09-03.md`, `spec_version: v1`:

    top_n: 20   group_by: family,iso_week   rank_by: t1_brier_improvement
    partition_seed: 20260903                alpha: 0.05

`top_n` lives ONLY in that file. `promote(t1_results, rule)` reads `rule.top_n`; there is no
`top_n` parameter anywhere in the module, so a caller cannot widen the search without editing the
spec -- which changes `prereg_sha256`. The test proves the width is file-driven by writing a TMP
copy of the spec with `top_n: 2` and asserting `promote` returns exactly 2 of 5 T1 screens.
