## Declared readings (each is a stated choice, carried in regime_census_defs where numeric)

- Decode: the index pass applies native_rows' per-row rules in order (as_of cut, record kind, then identity); duplicates use native_rows' own key (kind, ticker, game_key, receipt), both refused. A differential test pins row-for-row and count equality with native_rows on the fixtures.
- Trailing windows are (t - W, t]; a book change at t itself counts. Book change = (yes_bid, yes_ask, yes_bid_size, no_bid_size) differs from the previous population-accepted receipt; touch move = (yes_bid, yes_ask) differs. A ticker's first receipt is never a change.
- At an equal receipt, state rows fold before book rows ("received at or before t").
- Book age at an instant is 0 by construction (the instant IS the book receipt), so the book-age exclusion never fires there; it is applied in R3 / the lag census to the receipt before T_s.
- R2 score exclusion window is (break_start - 60, break_start]; the break's first receipt does not end the break. Missing fields count field_absent; present fields compare with their last present values, and recovered changes count change_across_absent_gap by field.
- R3 at t uses the latest state_changed True receipt T_s <= t and only while t - T_s < 300 s.
- R5 base = the last receipt at or before t - 300 (a full 300 s span); none -> no_trailing_300s_volume. V_lo is None, so R5 instants are threshold_unfrozen and only the decade distribution prints.
- R8 bands are half-open [0, 30) and [30, 120) from the latest score increase.
- Decided: two-sided mid <= 0.03 or >= 0.97; one-sided touch >= 0.99 or <= 0.01 (the low mirror is the declared symmetric reading of "a touch at 0.99 / 1.00").
- ladder_field_disagree is split price_yes / price_no (including yes_ask != 1 - no_bid) / size_yes / size_no; every split excludes the instant, and the orchestrator can see which one drives.
- Lag census: prior = the last population-accepted book receipt strictly before T_s (states fold first at an equal receipt); a change is searched in [T_s, T_s + 300). Unresolved at the end: never_within_300 (receipts seen, touch unchanged) / no_book_receipt_within_300 / censored_at_as_of.
- Peak working set and wall time go to <out>.run.json, not the artifact, so the artifact stays byte-identical under any input order. Linux has no peak_wset in psutil: resident set is used.
- R8 (FIX 1c, AMENDMENT 2 (a)): only a score increase on a state row with status live opens an R8 window; an increase first shown on a pre or final row still becomes the score baseline.
- One-sided rows (AMENDMENT 2 (g)): an accepted one-sided row (one touch null, ladder-consistent, not decided) feeds the book chain, the lag step and last_book, and it is also counted in population_exclusions as one_sided (it is in R6's population only). A side vanishing is a book change. No effect on 2026-09-22: every regime's pooled eligible count is 1386 and no one-sided row was accepted.
