# S722 PROPOSED input seam and adoption -- 2026-10-02

PAPER ONLY. No existing-file diff is required for this standalone module.
No live hook, scheduled task, capture configuration or M2 adoption is proposed.
The accompanying preregistration is PROPOSED and unsealed.

The CLI accepts canonical snapshot JSONL, one decision per line. A future
normalizer must run separately and write into a worktree-local scratch directory.
It must stream the raw shards, preserve source paths/line positions, use the
existing resolver for game/ticker linkage, and refuse unresolved identities.
That normalizer is outside this lane's owned files and has not been built.

Required snapshot keys: game_key, ticker, corpus, sport, orientation=home_yes,
as_of, outcome, lag_mode, measured_lag_s, measured_lag_source, carry_receipt_ts,
states, books; NBA also requires an independently frozen positive sigma.
Every timestamp is explicit aware UTC. State rows carry game_key, status,
event_ts and state; native mode also requires capture_ts. MLB state is
[inning, half, outs, base_state, home_minus_away]; half is zero for top and
one for bottom. NBA state is [home_minus_away, period, regulation_seconds_remaining].
The NBA live rule uses period < 4 or regulation_seconds_remaining > 0.
Book rows carry game_key, ticker, status=OK, capture_ts, price_ts and mid.
price_ts is the first receipt of the current unchanged-price run, never
the current polling time substituted for that run start.

Native state availability uses capture_ts and already includes measured lag.
Simulated state availability uses event_ts plus the explicitly supplied lag.
Do not use both delays. The MLB memo's median is a simulation parameter,
not evidence of live NBA delay. Input modes stay in separate summary cells.

CARRY is the declared earlier receipt. FRESH means the latest received
valid book at the decision; its agreement with the actual venue at that
instant is unverified. The carried anchor's event-aware suppression comes
from S542. The placebo freezes the anchor state under the same formula.
Missing or invalid current books produce a refusal rather than an older-book fallback.

   Treat every output as development; insufficient cells carry no interval.
