## Change and compatibility

Created scripts/platformkit/execution/venue_time.py with a fixed ASCII timestamp
grammar. An explicit Z or signed HH:MM offset is required. Fractions from zero
through nine digits are normalized to six before datetime parsing, truncating
without rounding. Finite int/float epochs are accepted; unsupported inputs,
non-finite numbers, booleans, and naive timestamps are refused. Refusal reasons
are exposed separately by venue_time_reason; accepted input returns no reason.

The only edited pre-existing implementation module is
scripts/platformkit/execution/markout_causal.py. Its _epoch signature is retained
and now delegates to parse_venue_time. The remaining function bodies, public
signatures, return structures, and reason literals are unchanged. As specified,
naive strings and numeric strings no longer pass through this timestamp parser.
The existing causal tests remain unchanged; one regression was appended to
assert selection of the first four-digit tick even when a later tick appears
first in the supplied sequence.
