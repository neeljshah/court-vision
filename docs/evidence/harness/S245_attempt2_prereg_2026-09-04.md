# S245 Attempt 2 preregistration - 2026-09-04

## Scope

This preregistration replaces the S245 attempt-1 data-limit conclusion only. It
uses the exact NBA-to-ESPN bridge in
`data/domains/basketball_nba/espn_nba_game_bridge.parquet` and the archived
per-player quarter observations in `data/cache/quarter_box/`, read one input at
a time. It does not write under `data/`.

## Fixed checkpoints and unit

The only scored checkpoints are end Q1, end Q2 (half), and end Q3. A scored
unit is an active player-stat observation for PTS, REB, or AST at one fixed
checkpoint. The differential archive retains each unit's game id, player id,
stat, checkpoint, as-of partial, final remaining target, both losses, and
partition. Confidence intervals cluster the paired losses by game id.

## Arms and loss

The state-conditioned arm uses elapsed-time fraction, game margin,
garbage-time flag, and the observed player partial to form an as-of
remaining-game distribution. The naive arm uses the unconditional
remaining-game distribution from the training states at the same checkpoint
and stat. Both arms are Gaussian distributions and use the shared evaluator
callback to produce Gaussian CRPS for every scored unit. Lower CRPS is the
better calibrated distributional score. No checkpoint, partition, or unit is
dropped because of its score.

## OOS folds and leakage controls

Every scored quantity is generated by
`scripts.platformkit.eval_gate.cpcv_engine.cpcv_evaluate`, with `n_groups=8`,
`n_test_groups=1`, `embargo_days=1`. This applies the evaluator's 48-hour
same-team purge, 3-day same-matchup purge, and symmetric nonzero one-calendar-
day embargo. The callback uses only its supplied training states for historical
distribution parameters; each test state exposes only its fixed-checkpoint
as-of features. The evaluator's vintage assertion is enabled for every state.

## Reporting rule

Report both arms' CRPS, their state-minus-naive paired CRPS difference, scored
n, and a game-clustered 95 percent bootstrap CI at each checkpoint split into
garbage-time and non-garbage partitions. The fixed rail is at least 30 game
clusters per checkpoint. A NULL or a state-conditioned result with higher CRPS
is retained and reported. The result does not designate either arm AHEAD.
