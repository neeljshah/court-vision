DEFINITIONS: d_i = loss_ref_i - loss_cand_i (positive mean => candidate has the lower loss); dbar_g = mean of d over game g's rows; series in first-appearance game order.
  dm_hln(x, h): T = len(x), gamma_k = (1/T) sum_{t>k} (x_t - xbar)(x_{t-k} - xbar), V = (gamma_0 + 2 sum_{k=1}^{h-1} gamma_k)/T, DM = xbar/sqrt(V),
  HLN = DM * sqrt((T + 1 - 2h + h(h-1)/T)/T), p two-sided from Student t(T-1); ci95 = xbar -/+ t_{0.975,T-1} * xbar/HLN. V <= 0 -> status NONPOSITIVE_VARIANCE, no stat.

  CORP: PAV of y on p with ties pooled; MCB = BS(p) - BS(pav), DSC = BS(r) - BS(pav), UNC = BS(r), r = base rate; BS(p) == MCB - DSC + UNC.
  Bias-corrected (Ferro and Fricker 2012): c = (1/n) sum_k n_k o_k(1-o_k)/(n_k-1) over bins with n_k >= 2; REL_bc = REL - c; RES_bc = RES - c + o(1-o)/(n-1); UNC_bc = n o(1-o)/(n-1).
