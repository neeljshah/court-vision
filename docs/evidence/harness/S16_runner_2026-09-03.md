## CHANGE (step 2) -- additive, one module

`scripts/platformkit/foundry_runner.py` (301 LOC, cap 300 respected):

- `run_pass(number, queue=None, batch=50)`. `queue=None` is the UNCHANGED legacy pass
  (`_legacy_pass` is the old body, moved not edited). With a `ScreenQueue` it claims up to
  `batch` hypotheses via `results_db.claim(batch, tier="T0")` and runs `tiers.run_tier` T0
  then T1 on the SCREEN side of the family partition.
- An EMPTY queue idles `poll_seconds` (default 60) and never touches `PASS_CONFIGS`.
- One `_append_summary` line per pass carrying `screens, screened_n (per family), promotions,
  charges, idle, seconds` (SF-2), plus a heartbeat file rewritten every pass
  (`FOUNDRY_RUNNER_HEARTBEAT`, default `data/ab_reports/foundry_runner.heartbeat.json`).
- T2/T3 come ONLY off `tiers.promote` (width `top_n=20` frozen in the prereg spec), run
  SERIALLY inside `with ledger_lock(...)`, and only when `--allow-charge` is passed.
  `run_charged` raises `ChargeNotAllowed` otherwise; `_promotions` catches it and prints
  `promotions_held ... reason=allow_charge_off`, so the default path holds promotions and
  charges nothing.
- `--legacy` reproduces the old CLI exactly: `run(args.max_passes, args.sleep_seconds)` with
  the 900.0 default and the six-config rotation.
- `screen_queue(sport, ...)` builds the corpus context. `close_join` supports soccer and
  tennis today; an unsupported sport raises there rather than being faked here.

`scripts/platformkit/foundry/seed_queue.py` (NEW, 89 LOC): enumerates `catalogue.entries()`
through `grammar.enumerate_family` over the grammar's own closed alphabet, upserts each
hypothesis and enqueues it at T0. It imports no tier and calls no `_charge_ledger`, so seeding
costs the FWER ledger nothing. `--limit` is the only bound; `--sport` restricts to one
catalogue sport.

No new dependency, no second runner, and `pod_supervisor.build_specs` is untouched -- the
existing `Spec("foundry_runner", (python, "-m", "scripts.platformkit.foundry_runner"), ...)`
keeps the new default path alive with no edit. NO DAEMON WAS STARTED by this lane.
