## 1. Method

One prior (`p0_asof`, the S86 incumbent Elo replay), five arms, all priced by the same closed form:

| arm | definition |
|---|---|
| `cell98` | `price_vec(p0_asof, state, sigma fit per phase cell on TRAIN, grid [6.0, 24.0] step 0.5)` -- **S98's `elo_sig` arm**, produced here by calling `s98.fit_sigma` itself |
| `wide` | the same per-cell fit on the **WIDENED grid [3.0, 60.0] step 0.5** |
| `param` | `sigma = exp(a + b log(rem_s + 30) + c \|margin\| + d is_p4)`, four coefficients fit on TRAIN by bounded `scipy.optimize.minimize` (L-BFGS-B) minimising the priced prior's Brier |
| `blend` | `sigmoid((1-w) logit(market) + w logit(param))`, ONE global `w` on TRAIN (the S94 form) |
| `recal` | the S94 global unregularised logistic on `[1, logit(market)]` -- the **NULL** |

`is_p4` is `period >= 4`, i.e. P4 **and** OT: the endgame regime, not literally the fourth period.
`rem_s` is the seconds left in the current regulation/OT frame, computed by the same clock
`price_vec` prices on (the test asserts `price_vec == 1.0` exactly where `rem_s == 0.0` and
nowhere else). Bounds, fixed before the run and never widened afterwards: `a` in [-5, 8], `b` in
[-2, 2], `c` in [-0.1, 0.1], `d` in [-3, 3], with sigma itself clipped to [1, 200] points. Three
starts are tried per fold and the lowest TRAIN Brier wins.

**Pricing is the same function at every sigma.** `s98.price_vec` reproduces the scalar
`price_checkpoint` to `2.22e-16` on 2,000 EVENLY spaced scored rows (`3.33e-16` on the full
screen) -- one ulp, from `scipy.special.erf` vs `math.erf`. The per-file test repeats the check at
**4.5, 27.5 and 47.0**: sigmas inside the WIDE grid and outside S98's, which is where the new arms
actually live.

**Strictly-before guard, two arms, both asserted at run time and tested.** For the prior: it must
be CONSTANT within a game (`max_prior_values_per_game = 1`), and re-pricing each game's first 4
ticks with every later tick of that game withheld must reproduce the full-frame price EXACTLY
(2,672 ticks bridged / 3,188 full-screen, `max_abs_delta = 0.0`, exactly zero, not a tolerance).
For the PARAMETRIC arm the same truncation check is run on the fitted coefficients:
`max_abs_delta = 0.0`. The test plants the classic leak (a within-game `groupby.transform("cummax")`
prior) and asserts the guard raises, and separately asserts `param_sigma` computed one row at a
time equals the whole-frame call row for row. **The guard's LIMIT is unchanged from S98**: a
per-game constant built from future data is invisible to a row-wise check; the as-of property of
`p0_asof` is inherited from S86's `replay(games, until=game_date)`, not re-proved here.

**Design.** Expanding walk-forward by game-first date on the S86 SCREEN side, 5 held-out blocks
after a train-only seed block, **purged by game** (train games asserted disjoint from test games)
and a **1-day embargo** (`train_date_max < embargo_cut <= test_start`, asserted per fold). The
per-file test flips the LAST fold's own held-out outcomes and proves that no fitted sigma and no
arm probability on that fold moves by one bit.
