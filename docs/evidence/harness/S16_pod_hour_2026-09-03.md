records each SOURCE file by its ABSOLUTE path (`C:\Users\neelj\nba-ai-system\data\domains\...`)

Linux pod every Windows path is missing, so all four scp'd corpora raised `StaleCorpusError`.

rewrites the sidecar with pod-local paths. It reproduced the local build exactly:
**25,834 rows**, matching `gate_corpus_soccer.sources.json`'s `n_rows` 25834. NBA, MLB and
tennis were left un-rebuilt (their domain sources were not shipped) and still refuse:
