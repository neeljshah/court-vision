## Encoding (matches the sealed segment() policy, rules.py:43-64 and POLICY.regulation)

| raw state (half, outs) | encoded for B/C/D | segment() fraction (raw = encoded) |
|---|---|---|
| Middle of inning i, outs 3 | inning i, bottom, outs 0 | (i - 1 + 0.5) / 9 |
| End of inning i, outs 3 | inning i + 1, top, outs 0 | i / 9 |
| Top or Bottom, outs 3 (the 3 transition ticks, as read here) | refused, model_state_refused (unchanged) | - |
| Middle or End, outs 0-2 | unchanged (half carried; the parser refuses it) | - |

base_state is carried as recorded. Both places encode: tick_row writes the mapped summary, and the parser
maps a raw Middle / End outs-3 summary itself, so an offline corpus that carries the raw half encodes the
same way.
