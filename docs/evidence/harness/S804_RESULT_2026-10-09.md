## Step 0 premise (read-only, main tree)
- On master, `receipt(main, '2026-10-06' or '2026-10-07', artifacts=True)` raises `night_artifact_digest_mismatch`; 10-08 returns.
- The only mismatching artifact is step `week`, file docs/evidence/forward/weeks/2026-W40_maker_forward.json. It was pinned as

- Cause: paper_night._steps writes week_out for the ISO week before the as_of date, so every night of a week rewrites one file.

## Change (+8 lines net, file at 300 LOC)
- `week_path(day)` derives the single week file that night writes: the ISO week before day+1, matching paper_night._steps.
  A test checks it against paper_night's own expression and the real budget template for every day in 2025-2027 (1,095 days).
- In the artifact loop, a digest mismatch where step == "week", the file is present and `item["path"] == week_path(day)` sets
  `week_artifact_rolling = 1` and skips that artifact. A later night's summary is never attributed to the older night. It adds
  no artifact_refusal_reasons, so accepted_receipt's night_artifact_refused count is unchanged. Every other mismatch still raises,
  including another valid week file pinned by mistake.
