## 4. Daily trigger (PROPOSED, not built; interim witness until S782c)

Clock trap: the box runs on America/Chicago, and Task Scheduler times are local. 09:30 local = 14:30Z
only until 11-01; after DST it is 15:30Z, after every cut. Proposal: task at 08:20 local, wrapper waits
until 14:30:00Z (13:20Z start CDT -> 70 min wait; 14:20Z start CST -> 10 min wait). Launched hidden
(the no-console-window rule: `hidden_launch.py`, as the paper-desk tasks). Steps, D = UTC date (= ET date at 14:30Z):

    cd /c/Users/neelj/nba-ai-system
    D=$(date -u +%F); P=$(date -u -d "$D -1 day" +%F)
    python -m scripts.platformkit.pregame_log.box_append --from $P --to $P --out data/cache/pregame_log/nba_box_2026_27.parquet  # from 10-21
    python -m scripts.platformkit.pregame_log.forecast_nba --day $D --repo-root /c/Users/neelj/nba-ai-system
    git add -- docs/evidence/forward/forecasts/nba/$D.jsonl
    git commit -m "S782 forecast log $D (PAPER ONLY)" -- docs/evidence/forward/forecasts/nba/$D.jsonl
    git push private master:trunk   # retry 3x, 60 s apart; never force, never rebase

Failure handling: box_append exit 3 -> stop, nothing forecast (a stale history is not used silently);
forecast exit 3 (`late`, `schedule_refused`, `prereg_*`, `write_in_progress`, ...) -> nothing written,
the JSON receipt appended to a dated log, counted; no commit. Push still rejected after 3 tries -> the
commit stays local, counted; the witness later reads LATE/UNWITNESSED and the rows are excluded.
Known gap: on a day with T1 < 16:30Z (noon ET under EDT) the cut is before 14:30Z and the day refuses
`late`; under EST (11-01 to 03-14) any tip >= 17:00Z keeps cut = 15:00Z. A second earlier task for
those days is the owner's call. Daily load: 1 schedule request + (1 + finals of D-1) <= ~16 requests,
one process at a time, RAM gate first; not in a focus-hour window.
