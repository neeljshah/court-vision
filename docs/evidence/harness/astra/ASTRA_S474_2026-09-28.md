1. **MUST-FIX-BEFORE-BUILD — Cutoff-dependent selection.** `S474_spec.md:10`; `ingame_scoreboard.py:126,227`. Emitted rows cannot pass a scoring boundary they postdate, and receipts after CUTOFF are filtered. However, a final at D 23:00 followed by another at D+1 01:00 moves close_ts beyond B(D+4), removing previously eligible history; a conflicting final also removes it. **Change:** reconstruct settlement at each consuming B(N), strictly before it, using versioned snapshots; require identical training membership when records after B(N) are appended.

2. **MUST-FIX-BEFORE-BUILD — Permanent emptiness conflates missing inputs with valid exclusions.** `S474_spec.md:16`; `ingame_scoreboard.py:210`. Missing shards merely increment `shard_absent`, so a capture outage can permanently freeze an empty file. **Change:** distinguish incomplete inputs from a complete zero-eligible-row result; only the latter becomes immutable. Record the required-shard completeness decision explicitly.

3. **MUST-FIX-BEFORE-BUILD — The promised game inventory cannot be reconstructed from ticks.** `S474_spec.md:15-16`; `ingame_scoreboard.py:229,243,276`. Zero-tick games have no returned settlement identity; `games` contains schedule entries and unsettled counts are aggregate. **Change:** expose a shared per-game settlement census, including zero-tick games; reconcile served, settled, conflicting, unsettled, ticks and rows. Namespace scorer counters separately from producer exclusions to avoid counting encoding refusals twice.

4. **MUST-FIX-BEFORE-BUILD — Unbounded cron predecessor.** `S474_spec.md:17,23`; `paper_night.py:143-158`. Sequential calls do not bound one large shard, total runtime, or a hang. **Change:** run the producer in a guarded subprocess with explicit RAM/deadline limits, cleanup, a persisted result, and guaranteed paper-night continuation after failure or timeout. Pinned step-name tests are not justification for bypassing those controls.

5. **MUST-FIX-BEFORE-BUILD — Public payload storage is an unreviewed scope change.** `S474_spec.md:16,22`; `scripts/hooks/public_allowlist.txt:33`; `ingame_scoreboard.py:67`. The proposed rows and manifests export publicly; manifests include absolute local paths. **Change:** store payloads under private `data/cache/forward/scoreboard/training/`, publish sanitized manifests/counts/hashes, declare a byte/retention budget, and relax the budget-template immutability requirement. Existing public ticks do not establish permission for continued venue-data redistribution.

6. **MUST-FIX-BEFORE-BUILD — Deterministic-manifest claim is false.** `S474_spec.md:10,16,20`; `ingame_scoreboard.py:57,67,113`. Appending post-cutoff records changes whole-shard hashes and `future_records`, even when emitted rows stay identical. **Change:** pin immutable source snapshots for reproducibility; distinguish row invariance from observation-dependent provenance. Case 10 must actually append future records, not merely change A.

7. **MUST-FIX-BEFORE-BUILD — “Write once” lacks transaction integrity.** `S474_spec.md:10,16,20`. Two producers can both pass the absence check and overwrite via `os.replace`; arbitrary existing bytes are accepted without validating their manifest. **Change:** serialize producers, validate existing row hashes/schema/config identity, report corrupt artifacts without overwriting them, and test overlap plus interrupted publication.

8. **MUST-FIX-BEFORE-BUILD — Acceptance cases are incomplete and internally inconsistent.** `S474_spec.md:10,20`. Keep `tick_after_final`, but test equality and repeated finals. Case 4 already contains the real-row case: the enumeration is 15 total, not 15+1.
