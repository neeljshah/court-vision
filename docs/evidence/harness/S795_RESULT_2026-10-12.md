## Build
- NEW scripts/platformkit/ingame/polymarket_meta_store.py (122 LOC). Sidecar `<output_root>/polymarket/_meta_done.json`
  = {version, root, ttl_sec, entries: {event_ticker: [recorded_at, game_start_time]}}, written through writer.atomic.
  A due market's meta is refetched when it is unknown, recorded on an earlier UTC day, stamped in the future, or >= META_TTL old.
  A fetch_error is never recorded. A corrupt, foreign-root or missing sidecar means a counted cold start
  (meta_store_read_errors / meta_store_root_mismatch / meta_store_entry_errors), never a crash. A write failure is retried next tick.
- polymarket_live_capture.py (300 LOC, at the cap): the refresh calls restore() instead of resetting meta_done.
  run_capture loads the sidecar. close_tick runs after commit_groups. The heartbeat gains `meta_fetched` / `meta_reused`
  (this tick, per sport), appended last.
- META_TTL = 1 h, from META_FIELDS: tokens, neg_risk, end_date_iso, minimum_order_size, seconds_delay and the fees
  are set at creation. game_start_time moves only on a reschedule, and gamma's start (re-read every 300 s) precedes it.
  accepting_orders and minimum_tick_size can move in-game, so their recorded staleness is bounded at 1 h.
  Steady-state meta load is about 1,482 / 3,600 s = 0.41 req/s.
  The same-UTC-day rule keeps one market_meta row per polled market in every day shard (cross_venue_link.meta_starts).
- Request RATE and the governor are untouched; only meta requests are removed. Row schema and row bytes are unchanged.
- DELIBERATE BEHAVIOUR CHANGE (record it): there are about 12x fewer market_meta rows in steady state (per 1 h, not per 300 s refresh).
- Not done (row scope b, widened 10-07): the per-tick book request shape. Books (~1,205 calls in the S793 trace)

  classify_event_state), not idle-and-unscheduled, and a start unknown or more than IMMINENT = 2 h ahead.

  This is adversarial A/B: the first build filtered after select_due and could starve an unscheduled live game.

  The 1d fold regex was extended to cover them.

  the same calls.
