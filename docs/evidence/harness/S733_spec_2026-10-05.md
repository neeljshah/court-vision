drain's watermark (`lower`) through this drain's drain_start_ts, then sets lower = this drain's watermark.
local_capture_backfill.py:207-209 queries the next drain with min_ts = max(watermark - 120 s, gap_floor),
and :270-273 writes trade_backfill_closed WITHOUT that min_ts; trade rows carry no request parameters either.

although the next query overlapped it. Real case (main checkout, read-only):
