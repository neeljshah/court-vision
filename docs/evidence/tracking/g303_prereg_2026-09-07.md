# G303 preregistration -- sealed before any distance is computed

Row G303. Question: at the production route's ACTUAL detector input, what is player
recall on the G296 adjudicated set, and how much does a native-resolution input buy?
This row MEASURES. It adopts nothing, proposes no production change, and moves no bar.

## 2. Arms

Every arm runs the UNEDITED human-gated production class
`src/tracking/advanced_tracker.AdvancedFeetDetector`, constructed as the pipeline
constructs it, with its raw model call captured by a wrapper in this harness. `src/` is
imported and run, never edited.

- ARM P -- the production route as measured in step 0. Whatever step 0 records is what
  ARM P uses. If step 0 contradicts the `imgsz = 640` source constant, ARM P follows the
  MEASURED value and the memo says so plainly.
- ARM R -- ARM P with `_infer_imgsz = 1920` and NOTHING else changed.
- ARM M -- ARM P with `_infer_imgsz = 1280` and nothing else changed. Sensitivity only;
  the headline comparison is P versus R.

The ONLY difference between P and R is the detector input size. Same weights file, same
`classes`, same `conf`, same `half`, same device, same decoded pixels, same crop.

ARM P is run TWICE (P and P_repeat) and the two detection CSVs are byte-compared BEFORE
any recall arithmetic. If they differ, each arm is treated as ONE draw and the memo says so.

## 3. Step 0, the binding premise

Recorded from at least 3 of the 24 frames, by wrapping the detector's model object and its
ultralytics predictor `preprocess` from OUTSIDE `src/`:
the shape and dtype of the array handed to the model, the `imgsz` / `conf` / `classes`
keyword values the route actually passes, and the shape of the preprocessed tensor the
network is run on. The measured values are printed verbatim in the memo.

BEFORE-CONDITION, binding: the production route's default detector input size is < 1920.
Printed at run time. If it is not < 1920 the premise is FALSIFIED and that is a valid result.

## 4. Matching rule

Footpoint convention: production's bottom-centre of the box with integer truncation and
image clipping, `x = (max(0,int(x1)) + min(W,int(x2))) // 2`, `y = min(H,int(y2))`, computed
in the coordinate frame the detector was actually given, then mapped back to native
1920x1080 coordinates by adding back any crop offset applied upstream.

PRIMARY rule: ONE-TO-ONE. Per frame, per arm, per tolerance, a minimum-cost one-to-one
assignment (Hungarian, `scipy.optimize.linear_sum_assignment`) between ground-truth points
and detection footpoints on Euclidean distance, with any pair above the tolerance rejected
after assignment. A detection may claim at most one ground-truth point.

SECONDARY rule, reported for comparability with G298 only: NEAREST -- a ground-truth point
counts as found if ANY same-frame detection footpoint is within the tolerance. Many-to-one.

TOLERANCES, all four reported every time: 25, 40, 50 and 100 px in 1920x1080 pixels.
50 px is the G296 sealed radius and is the HEADLINE. 40 px is reported because the row
brief named it. No tolerance is chosen after seeing a number.

## 5. Metrics

- recall = matched ground-truth points / denominator, per arm, per tolerance, per rule.
  The denominator is NAMED every single time it is printed. Primary denominator 86
  consensus points over 16 frames; secondaries are the pass-A-only (131) and pass-B-only
  (130) eligible counts. All three are reported every time a recall figure is reported.
- precision = one-to-one matched detections / total detections emitted on the SAME 16
  scored frames. This is a LOWER BOUND and is labelled as one everywhere it appears: the
  consensus set drops every point only one locator saw and excludes every bench, official,
  coach and spectator, so a correct detection of a real person who is not in the consensus
  set is scored here as a false positive.
- per-arm total detections, detections per frame, and the median distance from each
  accepted ground-truth point to the nearest detection.
- ms per frame and peak VRAM per arm, ONE draw each, DESCRIPTIVE only. The G303 spec
  declares timing out of scope, so no practicality conclusion is drawn from it.
- per-frame recall for the 16 scored frames, archived.

## 6. Uncertainty and tests

- 95 percent CI: percentile bootstrap over FRAMES, resampling the 16 scored frames with
  replacement, 10000 draws, numpy default_rng seed 20260907. For a DELTA the SAME resampled
  frame list is applied to both arms, so the interval is paired.
- Paired test: McNemar two-sided EXACT conditional binomial on the per-point detected /
  not-detected indicator, P versus R. An unpaired two-proportion test would be WRONG because
  both arms observe the SAME points on the SAME frames, so the two samples are dependent.
  All p values are NOMINAL and there is NO multiplicity correction across the four
  tolerances or the two matching rules. Points within a frame are not independent samples
  and no clustering adjustment is made.

## 7. Sign convention

delta = ARM R minus ARM P, in recall points (proportion), at a stated tolerance and rule.
POSITIVE delta means the native-resolution arm finds MORE of the accepted ground-truth
points than the production route does. NEGATIVE means it finds fewer.

## 8. What each outcome means, declared now

There is NO pass bar in the G303 spec and none is introduced here. A LARGE positive delta
on this clip-wide adjudicated set STRENGTHENS G298's attribution of the defect to input
resolution. A SMALL or ABSENT delta WEAKENS it and means G298's headline was specific to
its 15-frame span inside 19599-23399. The second outcome is the more important one to
report honestly and will be reported as plainly as the first. A step-0 finding that the
route does not feed what the source constant implies is a full success on its own.

## 9. Limitations, stated now rather than discovered later

Two model locators agreeing measures REPRODUCIBILITY, never CORRECTNESS, and both can be
wrong in the same way. G296b rated only 26/163 = 0.160 of its own player locations
`confident`, so every recall figure here inherits an approximately-positioned basis, and
G291 measured two model raters at Cohen's kappa 0.283 on an easier task. The two passes
agree on only 86 of 131 and 130 eligible points, so the consensus set is small and the
disagreement is large; every figure carries that. A detector that finds a player the
locators missed is scored as WRONG here, which bounds every recall figure from above and
below, and the 60 px consensus radius is itself wider than the 25 px tolerance scored.
One clip, one shot per frame, one draw per arm; 24 frames is clip-wide but thin. Recall is
not precision, and the precision reported here is a lower bound. This row measures the
route and one alternative input size and ADOPTS NEITHER.
