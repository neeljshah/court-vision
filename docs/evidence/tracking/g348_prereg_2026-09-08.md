## Binding premise and fixture rule

Before fixture selection, census every pod tracking output for
`court_calibration.json` or a schema-equivalent sidecar; record its writer
file:line, every input path, byte size, resolution, SHA-256, sidecar digest,
game, league, and frozen status. The census must report sidecars-present,
sidecars-absent, and frozen counts. If authentic sidecars are zero, report the
court-coordinate premise FALSE without constructing a replacement; only the
separately declared image-space liveness/trajectory scope may continue.

When authentic sidecars exist, select at least 30 non-frozen two-second windows
from at least three games, stratified by game, including both WNBA tables. Each
fixture uses the producer sidecar beside its original tracking table. The sealed
`fixtures.csv` has one source row per window and no duplicate fixture key.

coordinate-contract-valid twins: `A1_FROZEN`, `A2_ID_MERGE`,

`REFUSED`, never counted as a defect detection.

For every imported harness gate and fixture arm, record reached, evaluated, and
rejected integer counts plus a reason class. Contract refusal is neither
evaluated nor detected. A defect unavailable to the observations or invisible
to the harness is `UNIDENTIFIABLE`, not a detection. The implementation imports
the harness evaluator and G343's imported-gate status mapping; it does not copy
thresholds or gates.

(evaluated n > 0); per applicable planted defect detection >= 0.80 and
unchanged-window false rejection <= 0.05; defects the available observations
cannot identify (global mirror / scale without independent structure) are
marked UNIDENTIFIABLE, not counted as power; contract refusal is never counted
as detection.

No baseline-versus-candidate loss is planned. If a delta is later reported,
improvement = baseline loss minus candidate loss; positive = candidate better.
