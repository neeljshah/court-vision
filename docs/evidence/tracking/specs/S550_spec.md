3. MARKS: only rows with record_type == "snapshot" (focus depth rows); snapshot_bulk and any other type are counted `bulk_rows_ignored` and never marked against. A mark for an instant t and horizon h is the FIRST snapshot with time s in [t+h, t+h+10] (both bounds inclusive: s == t+h qualifies, s == t+h+10 qualifies, s == t+h+10.000001 does not); else the instant is unmarked for that h and counted `mark_missing`. Prior book for a decision instant is the last snapshot with s <= t and t - s <= 10 (equal 10 qualifies; 10.000001 -> no prior, counted `no_prior_book`). Snapshots need 0 < bid < ask < 100 in cents (bid == ask, crossed, 0 or 100 -> `snapshot_invalid_or_crossed`).
4. CENSORING: for an instant t with mid m0 and horizon h, the walk over snapshots in (t, t+h] returns "moved" at the first |mid - m0| >= 1 cent (equal to 1.0 moves), else "none"; if any gap between consecutive coverage points (starting from t itself, ending at t+h) exceeds 10 s (exactly 10 is not a gap) the instant is CENSORED for that h and leaves BOTH numerator and denominator; `censored` counts are receipted per h. Example: snapshots at t+4, t+9 (no move), h=60 -> gap t+9 to t+60 is 51 s -> censored; snapshots every 5 s to t+58, h=60 -> gap 2 s -> "none".
5. Same prior-book rule, same censoring.
