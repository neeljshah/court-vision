EVENT-AWARE ANCHOR (ONE time contract, all times epoch seconds as float; NBA plays and ticks are whole seconds, MLB receipts microseconds): at tick t with lag L (MLB: L = real, no shift), the KNOWN stream is the set of state entries with known_time <= t - L (NBA: known_time = play wallclock; MLB: known_time = state row capture_ts, L = 0), inclusive; every entry carries a play time (NBA wallclock; MLB state.last_play_ts). S(x) = the latest KNOWN entry with play time <= x (inclusive). The state tuple is what the formula consumes (NBA (margin, period, s_rem); MLB (inning, half, outs, base, diff)); tau_s = the play time of the latest known entry whose tuple differs from the entry before it (the first entry of a game counts as a change). The visible book at t is the STALE book (prices through the previous tick of the same game; MLB: through our own previous receipt): anchor mid = that previous price (so PROJ falls back to STALE exactly), tau_a = the time of the first tick of the run of equal prices that ends at the previous tick (the first tick of a game starts a run). project(...) returns (p, reason) with reasons, checked in this order: `state_unchanged` (S(t - L) tuple == S(tau_a) tuple: return the anchor mid object itself, even when mu would clip), `mid_event_reflected` (tau_a >= tau_s: a mid change at or after the latest known play; equality counts as reflected), `ot_boundary` (anchor and current straddle regulation/OT), `anchor_out_of_range`, `mu_undefined`, else `projected` = WP(S(t - L); mu from the anchor mid at S(tau_a)), with `mu_clipped` counted separately.
