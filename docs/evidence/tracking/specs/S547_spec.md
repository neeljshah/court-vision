- `wp3(diff, t_rem, mu) -> (p_home, p_draw, p_away)`: L = t_rem * 2.7/97, s = 1/(1+exp(-mu)), home goals ~ Pois(L*s), away ~ Pois(L*(1-s)) independent, outcome by diff + x - y over x, y in 0..GOAL_CAP, triple divided by its summed mass. diff is home minus away (int). t_rem == 0 -> (1,0,0) / (0,1,0) / (0,0,1) by sign of diff for every mu. Kickoff (0, 97, 0.0) -> (0.37090993817535484, 0.2581801236492902, 0.37090993817535495) within 1e-12. Symmetry: wp3(d, t, mu) == reversed(wp3(-d, t, -mu)) within 1e-12. For t_rem > 0: p_home strictly increasing, p_away strictly decreasing, p_home/(p_home+p_away) strictly increasing in mu.
- `invert_mu(diff, t_rem, mids) -> (mu, clipped) | None`: mids is a dict with keys from {home, draw, away}, each a finite real in [0, 1]. {home, away} or {home, draw, away} -> RATIO mode: target r = m_home/(m_home + m_away), solve p_home/(p_home+p_away) = r; the draw mid is validated but NEVER used (changing it leaves mu identical; mids summing to 1.03 are accepted); m_home + m_away == 0 -> None. {home} -> solve p_home = m_home; {away} -> solve p_away = m_away. {draw} alone -> ValueError('draw_not_invertible') (p_draw is not monotone in mu). Empty dict, unknown key, {draw, away} without home -> ValueError('bad_mids'). Target must lie strictly inside (0.005, 0.995), equality at either bound -> None; t_rem == 0 -> None (mu_undefined). Bisection on [-6, 6]; clipped = not (f(-6) < target < f(6)) (the mlb_mu rule, anchor_projection.py:113).
