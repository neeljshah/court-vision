EP and STATE: `ep(down, distance, ytg) = clip(EP1(ytg) + DOWN_ADJ[down] - DIST_SLOPE*max(0, distance - min(10, ytg)), EP_CLIP)`. `NflState` NamedTuple (margin, period, s_rem, poss, down, distance, ytg) -- period at INDEX 1 so anchor_projection.decide's ot_boundary rule (:184, `tuple[1] >= 5`) applies unchanged; poss in {1 home, -1 away, 0 unknown}; down 0 means no drive term. drive = poss*ep(...) iff poss != 0 and down in 1..4 and s_rem > 0 and not (clock_seconds_remaining == 0 and period in (2, 4) or period >= 5 with s_rem == 0) (possession survives the 1->2 and 3->4 quarter breaks, never halftime or the end); else 0.
 3. `nfl_wp(state, mu=0.0)`: m = margin + drive + mu*s_rem/3600; s_rem == 0 -> 1.0 if m > 0.5, 0.0 if m < -0.5, else 0.5 (end of regulation tied = OT a priori 0.5; end of OT tied = 0.5); else sd = SIGMA*sqrt(s_rem/3600) and wp = 1 - 0.5*phi((0.5 - m)/sd) - 0.5*phi((-0.5 - m)/sd) (the mlb_we tie band). OT (period >= 5) uses the OT clock as s_rem with the same drift and sd (regular-season 10-minute OT; postseason rules out of scope). Strictly increasing in mu whenever s_rem > 0. `nfl_mu(state, p) -> (mu, clipped) | None`: None unless ANCHOR_LO < p < ANCHOR_HI (the stern_mu rule) and None when s_rem == 0; else 60-step bisection on [-30, 30] on target p; clipped iff p is not strictly inside (nfl_wp(state, -30), nfl_wp(state, 30)). Wrong types (bool, str, None, NaN, inf, float where int is required) and out-of-range fields raise ValueError via _real/_int (margin -200..200, period 1..9, s_rem 0..3600, poss -1..1, down 0..4, distance 0..99, ytg 0..100).
