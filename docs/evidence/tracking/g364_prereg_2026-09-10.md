# G364 learned court-presence preregistration

Contract: `docs/evidence/tracking/VERIFIER_CONTRACT.md`.

Scope: preparation only. No source is pinned, no frame is rated, no head is fit on
development labels, and no validation metric is computed by this commit.

Frozen extractor: torchvision ResNet-18 ImageNet1K V1, average-pool 512-vector,
evaluation mode, all backbone parameters frozen. The pod cache entry must be named
`resnet18-f37072fd.pth`; before embedding, the finisher records its full SHA-256 in
`model.json` and aborts if its filename digest prefix is not `f37072fd`. This full
hash is NOT VERIFIED in the preparation environment because the pod is unreachable.

Head: four-class linear softmax logistic regression over the frozen 512-vectors,
classes in this exact order: USABLE_COURT, CLOSEUP, CROWD_GRAPHICS, UNKNOWN. Seed
364; L2 0.0001; 400 full-batch gradient steps; learning rate 0.05. Cache every
embedding once under the pod scratch directory, then delete that scratch directory
after output artifacts are written. No backbone fine tuning is permitted.

Abstention: margin is top probability minus second probability. On development
labels only, evaluate thresholds 0.05, 0.10, 0.15, 0.20, 0.25, and 0.30. Select the
largest threshold with development predicted-court precision at least 0.90 and
USABLE_COURT recall at least 0.80; if none qualifies, stop as NOT VALIDATED. Freeze
the selected threshold before validation selection. A margin below it is ABSTAIN;
otherwise the prediction is COURT only for USABLE_COURT and NON_COURT otherwise.

Sources: pin every video before use in `sources.csv` with YouTube id, requested
offset, full file SHA-256, fetch UTC, absolute pod path, byte size, width, and
height. An NBA game id alone is never a source. Fetch using
`/workspace/YTDLP_RECIPE.txt` into `/workspace/g364_scratch/`, never into data.

Development sampling: at least 20 pinned sections, 8 game ids, and 3 competitions.
For every section take exactly 12 evenly spaced interior indices:
`floor((i + 1) * (frame_count - 1) / 13)` for i = 0 through 11. The sheets contain
only frame identity and pixels, not scores, probabilities, margins, predictions,
or labels. Two blind raters and blind adjudication supply development labels.

Validation sampling: before rating, seal a game-disjoint manifest with at least 300
frames from 30 sections, 10 game ids, and 3 competitions. Use frozen predictions to
select at least 60 COURT, at least 60 NON_COURT, and remaining ABSTAIN frames; each
section is sampled by the same interior-index rule. If development NON_COURT reach
is below 20 per mille, report LIMIT without large validation sampling. Stable frame
key is `source_sha256:section_id:frame_index`; one evaluator state is emitted per
key, never one state per game. Any future paired comparison uses the shared
walk_forward or cpcv_evaluate evaluator with purge and symmetric nonzero embargo,
and archives only evaluator records as its loss series.

Scoring bars: validation is game-disjoint and sealed before rating; at least 300
validation frames, 30 sections, 10 games, 3 competitions, and 30 rows per scored
class; predicted-court precision at least 0.90 and USABLE_COURT recall at least
0.80, each with Wilson 95 percent intervals. Report kappa, UNKNOWN share,
abstention share, full confusion, and per-competition results. Never refit the head
or change the threshold after validation sealing. The sign convention for any
future delta is improvement = baseline loss minus candidate loss; positive means
candidate better.

The finisher records SHA-256 values for every G364 route file exercised on the pod.
No src edits, flags, router thresholds, content gate, daemon, register, ledger, or
data files are changed by this preparation lane.
