# G351 PREREG - Ball Coordinate Scale (2026-09-08, LOCAL)

Written before G351 reads the tracking mirror or calculates a census/re-join metric. This is a
preparation-only lane; no local table was opened before this seal. Contract:
`docs/evidence/tracking/VERIFIER_CONTRACT.md`, sections A and B. No scored comparison is planned.

## 1. Binding premise and scope

The finisher enumerates every immediate directory under `data/tracking/` that contains both
`tracking_data.csv` and `ball_tracking.csv`. For each clip, it opens one CSV at a time, uses finite
coordinates only, and prints ball and player p01/p99 ranges on x and y. Player samples are both
endpoints of `bbox_x1,bbox_x2` and `bbox_y1,bbox_y2`; ball samples are `ball_x2d,ball_y2d`.
Percentiles use the fixed linear rank rule `i=(n-1)*q`, interpolating its two adjacent sorted values.
The premise passes when at least one clip has `ball_range/player_range > 1.5` on either axis. If the
share is zero, the memo reports `PREMISE FALSE` and stops; G349 is then window-local.

## 2. Fixed classifications and outputs

Known coordinate frames are original (reported source width x height when present), crop (source
width x max(source height-60,1)), detector (640x352), and panorama (3698x500). A ball table is
classified by the nearest normalized distance from its p99 x/y extent to these known width/height
extents. Ties use the listed order. Missing source dimensions yield `UNKNOWN_NO_SOURCE_DIMENSIONS`,
not a guessed original/crop class. `ranges.csv` includes every scoped clip, its source dimensions from
either header if supplied, league/sidecar version if present, all four ratios, inferred frame, and
`anomalous` (ratio > 1.5 on either axis). Counts are zero-padded six-digit integers and shares are
additive per-mille integers.

For only clip paths containing `0022500630`, `0022500906`, or `0022500799`, `rejoin.csv` compares the
fixed 60-pixel point-to-rectangle radius count before and after this reader-side affine rescale:
`new=(old-ball_p01)*(player_range/ball_range)+player_p01`, independently by axis. It also reports all
selected live/detected finite-ball frames; no missing window is silently treated as zero. This is a
screening re-join, not correctness evidence.
