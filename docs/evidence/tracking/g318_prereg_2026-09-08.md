## Premise construct (step 0, binding before-condition)
P1 ALWAYS TRUTHY: `probe_source()` in `scripts/platformkit/tracking/source_timebase.py`
returns a dict literal on BOTH of its paths -- the reader-failed path and the
reader-opened path -- and a dict with keys is always truthy in Python. The premise is
proven by citing both return statements with `file:line` and by running the function
locally against (a) a path that does not exist and (b) an existing zero-byte `.mp4`,
PRINTING both return values verbatim.
P2 CONSEQUENCE: every caller that branches on `if source:` therefore takes the true
branch for a probed job, so a reader failure and a never-probed source reach the ledger
as the same all-null row.
FALSIFIER: if either local run returns a falsy value, the premise is FALSE. The row then
STOPS, writes the memo, commits, and reports PREMISE FALSE. No fix is written.
NOTE STATED NOW: the reader is `cv2.VideoCapture` (ffmpeg underneath), not a literal
`ffprobe` subprocess. The spec's reason token `ffprobe_rc` is kept as the name for
"the reader could not open the file"; no token is renamed to suit the implementation.

## The field's value vocabulary (fixed here, never re-derived later)
`probe_status` is a string on every new ledger row, one of exactly these six values:
- `ok` -- the reader opened the source and both a positive frame rate and positive
  dimensions were read.
- `failed:missing` -- the path does not exist.
- `failed:ffprobe_rc` -- the path exists and the reader would not open it.
- `failed:no_video_stream` -- the reader opened it and reported no positive dimensions.
- `failed:parse` -- the reader opened it with dimensions but no positive frame rate.
- `not_probed` -- no probe was attempted for this row.
`ok` and the four `failed:` values are decided inside `probe_source()` and carried on an
ADDITIVE `status` key of its existing return dict; the return shape keeps its five
current keys with their current names and meanings and never becomes falsy (contract
B2). `not_probed` is what the daemon records when it holds no probe result for the row.
