## The denominator contract this row will define

Six names. The first three are the candidates the spec names at the producer site; SOURCE is
context; the two RECONSTRUCTED names are explicitly labelled reconstructions and are never written
into the route's own sidecar.

| name | meaning | where it is knowable | who uses it |
|---|---|---|---|
| SOURCE | frames the container declares for the whole file | ffprobe `nb_frames`, else round(duration x r_frame_rate) | context only; never a rows-per-frame denominator here |
| DECODED | frames read from the container by the route's prefetcher for THIS run | only inside the prefetcher; the route computes a whole-file value and only when the frame cap is null | route sidecar key `decoded_frames` |
| EVALUATED | frames handed to the detector after stride and after the frame cap | only inside `src/pipeline/unified_pipeline.py`; the counter that decides the cap is incremented after a detector-gated test, so the value cannot be known before the run | route sidecar key `evaluated_frames`; null in this route |
| EMITTED | frames carrying at least one person row | the tracking table | EVERY rows-per-frame number in the G310 evidence today |
| PROCESSED_RECON | distinct frames present in the ball table; a RECONSTRUCTION of EVALUATED after the gameplay gate | the ball table, after the fact | this row's recomputation only |
| DELIVERED_IN_SPAN_RECON | strided positions between the first and last frame the run wrote; a RECONSTRUCTION of DECODED restricted to the covered span | the two tables plus the stride, after the fact | this row's recomputation only |

A denominator recorded by the harness after the fact is a RECONSTRUCTION, not the producer's count.
The route's null stays null until a human applies the PROPOSED diff.

## The sidecar fields

New module `scripts/platformkit/tracking/g331_evaluated_frames_sidecar.py` writes a NEW file,
`g331_frame_denominators.json`, next to a route output directory. The route's own
`evaluated_frame_count.json` is READ ONLY: it is never rewritten, and no existing key of it and no
column name or meaning of the archived G310 CSVs is changed (B2). Keys, and where each is fed from,
declared in advance:

- `schema_version`, `producer_version` -- constants of this module.
- `decoded_frames` -- route sidecar `decoded_frames`, VERBATIM; null when the route says null.
- `evaluated_frames` -- route sidecar `evaluated_frames`, VERBATIM, NEVER a reconstruction.
- `evaluated_frames_reason` -- the route sidecar's `reason` string, VERBATIM.
- `frame_cap` -- route sidecar `max_frames`, VERBATIM.
- `stride` -- route sidecar `stride`; when that is null, the modal positive difference between
  consecutive distinct frame ids in the ball table, and then `field_sources.stride` says so.
- `emitted_frames` -- count of distinct `frame` values in `tracking_data.csv`.
- `processed_frames_reconstructed` -- count of distinct `frame` values in `ball_tracking.csv`.
- `delivered_frames_in_span_reconstructed` -- (max - min) // stride + 1 over the union of frame ids
  in the two tables; null when the stride is unknown or fewer than two distinct ids exist.
- `source_frames` -- ffprobe `nb_frames` when it is a positive integer, else
  round(duration x r_frame_rate); null when the source file is absent.
- `source_frames_method` -- one of `ffprobe_nb_frames`, `ffprobe_duration_times_rate`,
  `source_absent`, `ffprobe_unavailable`.
- `field_sources` -- a map from each field above to the artifact it came from.

If the true EVALUATED count proves knowable only inside `src/pipeline/unified_pipeline.py`, a
PROPOSED diff of 3 to 5 lines is written to
`docs/research/organization-sprint/G331_PROPOSED_evaluated_frames.md` (gitignored, local-only) and
its SHA-256 is carried in the memo. No file under `src/`, `kernel/`, `api/`, `intel/` or
`scripts/team_system/` is edited.

## The two reader fixes, and how before and after is shown

FIX 1 -- `scripts/platformkit/tracking/g310_instance_key.py:80` selects the denominator with a
truthiness test, so an explicit `evaluated_frames` of 0 reads as absent and silently falls back to
`frames_with_rows`. It becomes an `is not None` test. The SAME truthiness test occurs in the shared
reader at `scripts/platformkit/tracking/g310_native_input_arm.py:41`, which is the same defect at a
second call site; both are fixed together. Declared behaviour after the fix: with an explicit 0 the
denominator SOURCE reads `evaluated_frames`, and the ratio stays null because the denominator is
zero -- a zero denominator never produces a number. Before and after is shown by a test that pins
an explicit 0 through both readers and asserts the source string.

FIX 2 -- the percentile at `scripts/platformkit/tracking/g310_native_input_arm.py:33-37` is
documented as nearest-rank but computes `sorted[round(0.95 x (n - 1))]`, a rounded linear-position
index. DECIDED IN ADVANCE: KEEP the rounded index and RELABEL the docstring. Changing the estimator
would change the MEANING of the already-committed `p95_norm_footpoint_step` and
`p95_norm_step_instance` columns, which B2 forbids. `g310_instance_key.py` imports this one
function, so the relabel covers both users. Before and after is shown as VALUES, not as a rewrite:
for EVERY archived run both estimators are computed on the same step sample taken from
`docs/evidence/tracking/g310_attempt2/g310_attempt2_rows_part01.csv.gz` and printed side by side
with n = the step-pair count. No committed column is rewritten.

## The recomputation rule

For each archived run in `docs/evidence/tracking/g310_attempt2/` -- every run in the archive, no
head slice -- the numerator is the run's person-row count and the table prints one ratio per
denominator, each cell carrying its denominator name and either n or the words NOT KNOWABLE:

- EMITTED: distinct person-row frames. NOT KNOWABLE when the run emitted no person rows.
- PROCESSED_RECON: distinct ball-table frames, cross-checked against the committed `ball_rows_total`
  for that run; if the two disagree the cell is NOT KNOWABLE and the disagreement is printed.
- DELIVERED_IN_SPAN_RECON: requires at least two distinct frame ids and a stride that divides every
  observed gap between consecutive distinct frame ids; NOT KNOWABLE otherwise.
- EVALUATED (as the route defines it): the route's own value, or NOT KNOWABLE.
- DECODED (as the route defines it): the route's own value, or NOT KNOWABLE.
- SOURCE: ffprobe `nb_frames` from the committed corpus probe in
  `docs/evidence/tracking/g310_pilot_pre_prereg/pilot_summary.json`, matched by game id; NOT
  KNOWABLE for a game absent from that probe.

Ratios are printed to six decimal places. INFLATION of the EMITTED denominator is reported per run
as the ratio of the EMITTED-denominator rows-per-frame to the PROCESSED_RECON rows-per-frame, to
six decimal places, together with the frame shortfall written as a fraction
(PROCESSED_RECON minus EMITTED) over PROCESSED_RECON. No share is written as a percentage figure.

EXPECTED NOT KNOWABLE, declared now: EVALUATED and DECODED as the route defines them, for EVERY
committed run, because the producer returns before computing either whenever the frame cap is not
null. If any run contradicts that expectation it is reported as a contradiction, not smoothed over.

The companion CSV
`docs/evidence/tracking/g331_evaluated_frames_sidecar_2026-09-08/rows_per_frame.csv` carries the
same table with every integer cell zero-padded to six digits.
