1. Retain full native originals and raw parent outputs before any pod stage. Record actual resolved paths, bytes, dimensions, rational PTS, source digest, start-frame/frame-cap arguments, absolute frame indices, producer rows, silence, and read-back hashes for all selected inputs. No replacement, redraw, rematch, or fresh tracker reset is allowed.
2. Before launch, bind the archived UnifiedPipeline, AdvancedFeetDetector, alternate active path, pose and detector cadence, prefetch cache keys, crop constants, dimensions, padding, bbox tuple order, effective library configuration, every loaded model, route, input, and runtime asset. Missing exercised identity is NOT VALIDATED.
3. Replay each of the 53 sealed short windows observer-only through its actual producer route, preserving surrounding in-window state. At each of the frozen 60 ticks, capture decoded native array/hash, post-crop array/hash, model input key/shape, raw model box, post-tracker box, CSV values, and serialized join key.
4. Record model-call and cache-frame identity at the call site, including prefetched frames. A historical decoder identity remains UNKNOWN. A disagreement in an identity bind ends coordinate-cause attribution at its first mismatch stage.
5. Independently join original G402 raw CSV values using source digest, window, frame, track, and event. Duplicate and absent joins remain failures. Record G406 preprocessing as a separate comparator; do not substitute it for the producer path.
6. Derive origin, scale, padding, crop, and xyxy/yxyx transforms from executed constants and code before comparison. Use exact integer or rational arithmetic for crop and serialization. Detector floats remain separate. Do not fit a translation from the 51 frozen matches.
7. Run known-geometry CONSTRUCT cases for origin, corners, crop boundary, and tuple order through the relevant functions. These controls supplement, never replace, all 60 native ticks.
8. Render stored boxes, code-mapped boxes, and actual detector input separately in native pixels for all 60 ticks. Reuse the frozen associations only for descriptive residuals; any fresh detector assignment is separate.
9. A cause can be established only when the first erroneous frame-contract boundary and responsible code/export site are shown by an executed declared transform on at least 30 distinct native frames. Mixed or unexplained causes remain PARTIAL; no universal correction is claimed.

The acceptance bars are byte-for-byte those in docs/evidence/tracking/specs/G409_spec.md: all 60 keys and every row/silence accounted; exact source/window/CSV joins; zero substituted frames; all 60 planned ticks plus supported-frame n separately; pre-launch model/route/input hashes; complete stage records; and two saved-output reproductions identical.
