# G310 Native-Input Arm Preregistration

Sealed before any arm was run and before any proxy was computed. Row G310, worktree a1, spec `docs/evidence/tracking/specs/G310_spec.md`.

Scope: a SCREENING comparison of the production basketball daemon route at its production default detector input size against the same route with the detector instance attribute `_infer_imgsz` set to 1920. There is NO ground truth in this row, so every number it produces is a proxy and none is a quality measure. No recall, precision, accuracy, registration or harness-pass claim is made or may be derived from it.

Predeclared premise (binding before-condition, step 0): instrument the route as `scripts/platformkit/track_daemon.py:build_command` calls it and print the effective input size the detector receives at the inference call site. If the printed value is NOT below 1920, this row is PREMISE FALSE, work stops, and the memo records that as the result.

Predeclared inputs: sources under `/workspace/nba-ai-system/data/footage_corpus/`, read-only through the `/workspace/wt/a1/data` link. Every candidate is probed with `ffprobe`; only measured 1920x1080 sources are eligible and the rejected count is reported with its reason. Three eligible games are used.

Predeclared arms, one difference: ARM P is the production route, unmodified, with no attribute set. ARM N is the same route, same argv, same weights, same conf, same classes, same start frame, same frame cap, same code path, with `_infer_imgsz` set to 1920 on the detector instance after construction. Both arms carry the same passive call-site recorder, which appends the observed `imgsz` kwarg and forwards every argument unchanged. No third difference is introduced. No file under `src/`, `domains/`, `api/` or `kernel/` is edited, and no production default on disk is changed.

Predeclared runs: 3 games x 2 arms + 1 ARM P repeat on the first game = 7 route runs. Each run holds its own process and its own wall stop of 3,600 s; a run that exceeds it is reported BUDGET LIMIT for that game and arm, never silently dropped. Each run reports its wall seconds either way.

Predeclared proxies, image space only, computed per game per arm with the denominator named: person rows; person rows per evaluated frame, the denominator being `evaluated_frames` from the route's own `evaluated_frame_count.json` sidecar and never the count of frames that happen to have rows, which is reported separately as `frames_with_rows`; distinct track ids; median track length in rows; ball rows detected out of ball rows total; and the p95 nearest-rank per-track consecutive footpoint displacement normalised by the probed `source_height`, with the pair count as its denominator. The footpoint convention is the image-space bbox BOTTOM-CENTRE, `((bbox_x1 + bbox_x2) / 2, bbox_y2)`.

Predeclared sign convention: a HIGHER person-rows-per-evaluated-frame, a HIGHER distinct-track-id count, a HIGHER median track length and a HIGHER detected-ball-row count would each be consistent with more detection; a LOWER p95 normalised footpoint step would be consistent with steadier association. Consistency is not evidence. More rows per frame can mean more players found OR more false boxes, and this row cannot tell those apart; G303, which scores recall against the G296 frames, is the row that can.

Predeclared bar: 3/3 games complete BOTH arms within 3,600 s each and every proxy is tabulated with its denominator. There is NO quality bar and NO pass bar. A proxy table showing NO difference is a FULL SUCCESS. The ARM P repeat is reported as a stability check only; if the repeat's proxies differ from the first ARM P run, every arm is treated as ONE DRAW and the memo says so.

Predeclared operational gates, not evidentiary bars: proceed only when `nvidia-smi` reports at least 8192 MiB free VRAM, re-probing every 60 s otherwise; `track_daemon` is never stopped, signalled or interrupted; `du -sm /workspace` is reported verbatim and an empty result is UNKNOWN, never 0, and never a stop; only a failed `dd conv=fsync` probe stops the row.

Predeclared non-targets: no production default is changed, no threshold or filter is moved, nothing is adopted and nothing is proposed. `yolov8n.pt` on the pod is not deleted or overwritten. The deployed `/workspace/nba-ai-system` tree, `data/tracking/`, the daemon ledger and its `passed` field are not written. `docs/evidence/tracking/TRACKING_GAPS_2026-09-01.md` is not edited.

Contract: `docs/evidence/tracking/VERIFIER_CONTRACT.md`, section B, with A9 (full source path, byte size and resolution per input) and H1 (named denominator) binding. Calibration language only; no dollar, ROI, profit or edge language appears in any artifact of this row.
