# G76 blind sample

Seed: `76092026` (Python `random.Random`).

The manifest has 11 identities selected without replacement from each of the 11 census clips (121 tiles total). The renderer accessed only `frame_index` and row position; it did not read the census `label` field. Each board is a 5 by 3 layout of original 640 by 384 tiles, with no census labels displayed.
