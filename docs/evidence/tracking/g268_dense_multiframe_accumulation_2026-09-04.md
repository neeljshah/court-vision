## One joint objective, then the binding control

This is not G266's four-constraint transport-to-reference solve. For every frame, fixed bright/low-saturation support was newly extracted around the pre-existing G253 line geometry; G222's direct seed-to-frame map relates that source frame to the one global seed image-to-court map. The optimizer minimized the sum of squared mapped-support distances to the four named court lines over all 41 frames at once. It used `scipy.optimize.least_squares`, trust-region reflective (`trf`), linear loss, `x_scale='jac'`, maximum 2,000 evaluations, with `ftol`, `xtol`, and `gtol` each set to `1e-10`. It stopped after 34 evaluations on the `xtol` criterion; objective cost was 1,229.479 and first-order optimality 2,409.109. Those optimizer values are diagnostics only, not evidence.

The published G233d map was comparison-only. On G253's full 634-point court-line sampler, **232 points project inside the native frame under both maps**. That named dense shared-in-frame denominator, not the 634 full-court projections, is the control population. The discrepancy is median **8.272 px**, p90 **14.230 px**, and **maximum 25.078 px**; all 634 projections are 41.770 / 952.284 / 15,723.578 px. The same comparison for G253's one-frame lines-only control was 231 shared points of 634 and 2.849 / 3.992 / 4.344 px. The dense accumulation does not reproduce the published map comparably with that known one-frame result. This is a worded judgement, not a new numerical bar.

The harness emitted a [seed overlay](g268_dense_multiframe_accumulation_artifact/joint_fit_seed_render.jpg), but because the control failed it was not eye-checked and is not independent-geometry evidence. No G257-style eye claim is made.
