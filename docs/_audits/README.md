# Internal audit archive

Dated audit notes from internal doc-cohesion / dead-file / pipeline-validation passes. Kept under `_audits/` (underscore prefix) so they don't clutter the top of `docs/` for first-time readers, but checked in because they document *how* the repo was kept honest — useful for evaluators reading backwards from a current state.

These are point-in-time snapshots. If a claim here conflicts with current state, current state wins.
