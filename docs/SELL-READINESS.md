# Sell-Readiness Checklist

> This is a **DECISION-SUPPORT** package: a calibrated 4-sport (NBA / MLB / soccer /
> tennis) pregame + in-game predictor with a fail-closed eval gate and a reproducible
> calibration record. It is **NOT** a picks / profit / +EV / ROI product. The honest,
> defensible claim is calibration and sharpness -- matching the Shin-devigged closing
> line within noise on team-strength markets, plus a measured, calibrated in-game
> conditioning gap. `edge_claimed=False` everywhere; no $ figure is produced or implied.
> The single truth source for what may / may not be claimed is
> [docs/JOB_EVIDENCE_PACKET.md](JOB_EVIDENCE_PACKET.md).

The trust moat is the discipline, not a number. "Honest no-edge / MARKET-EFFICIENT HERE"
is a first-class feature. The moment any copy implies a guaranteed $ edge, the moat
collapses.

## SELLABLE NOW (reproducible, offline, committed)

- [x] **Slim, installable package** -- `pyproject.toml` + `requirements-predictor.txt`
      define a lean predictor extra; not the full research tree.
- [x] **Containerized** -- `Dockerfile.predictor` builds the buyer-facing image.
- [x] **One-command predictions** -- `python -m scripts.platformkit.predict_matchup
      --sport <s> --home <h> --away <a> [live-state flags]` returns a calibrated pregame
      (and optional in-game) JSON / markdown result, badged `edge_claimed=False`.
- [x] **Startup CALIBRATION CONTEXT banner** -- `predict_matchup` prints (to stderr, so
      stdout JSON stays clean) the last OOS Brier (golden anchor), the devigged-close
      Brier, the last recalibration date, and the binding "calibration not edge; pregame
      market efficient" line. Sourced from `eval_gate/baselines/*.json`, never authored.
- [x] **Fail-closed eval-gate scoreboard** -- `python -m scripts.platformkit.eval_gate.run_gate
      --golden` runs the leak-free walk-forward on the committed synthetic golden anchor,
      scores BSS / Brier (+ clustered CI) / ECE / DM vs the devigged close, labels
      BEATS / MATCHES / BEHIND, and blocks only on regression-vs-frozen-baseline or a
      leak (never on a non-beat). Offline, < 60s.
- [x] **Track-record ledger replay_proof** -- `python -m scripts.platformkit.ledger.replay_proof`
      recomputes Brier / ECE / DM-vs-close on the committed fixture ledger in < 30s.
- [x] **Public calibration-record page** -- [docs/CALIBRATION_RECORD.md](CALIBRATION_RECORD.md),
      generated by `python -m scripts.platformkit.calibration_record --write`: per-corpus /
      per-sport reliability tables (predicted vs observed, n per bin, SPARSE flag at n<30),
      Brier-vs-devigged headline, per-source badges, and "MARKET-EFFICIENT HERE" as a
      first-class verdict front-and-centre. Optional guarded matplotlib PNGs (`--png`).
- [x] **Buyer docs** -- `docs/PREDICTOR_PLATFORM.md`, `docs/PREDICTOR_QUICKSTART.md`,
      `docs/PRODUCT_ONE_PAGER.md`, README headline (CV -> Origin funnel).
- [x] **Honest framing baked in** -- every numeric surface is badged by SOURCE
      (model in-corpus / devigged-market / score-only-anchor); a visible disclaimer; the
      retracted measurement artifacts are never printed as current results.
