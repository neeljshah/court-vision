  <action>
    Create scripts/compare_models.py (max 120 LOC, type hints, Py3.9):

    ```python
    """
    compare_models.py — Validate new model metrics vs previous before committing to git.

    Usage:
        python scripts/compare_models.py --stat pts --threshold 0.02
        python scripts/compare_models.py --stat all --threshold 0.02

    Exit codes: 0 = all pass, 1 = any fail
    """
    ```

    Metric storage: Read from `data/models/model_metrics_history.json`.
    - Structure: {stat: [{r2: float, mae: float, trained_at: str}]}
    - If file doesn't exist → create with current model metrics → exit 0 (first run, no comparison possible)

    Core function:
    ```python
    def compare_models(stat: str, threshold: float = 0.02) -> dict:
        """Compare new vs previous model R2. Returns PASS/FAIL dict."""
    ```

    Loading new metrics: call `_load_new_metrics(stat)` which imports PlayerPropsModel and calls `.score()` on test data, OR reads from `data/models/props_{stat}.json` if it has a `r2` key. Prefer the JSON approach (no GPU needed in CI).

    Loading prev metrics: read last entry from `data/models/model_metrics_history.json` for the stat.

    After comparison: append new metrics to history file (regardless of pass/fail) so history grows.

    Print output per stat: `[PASS] pts: R2=0.50 (prev=0.47, delta=+0.03)` or `[FAIL] pts: R2=0.44 (prev=0.47, delta=-0.03)`

    CLI main():
    ```python
    if __name__ == "__main__":
        import argparse, sys
        parser = argparse.ArgumentParser()
        parser.add_argument("--stat", default="all")
        parser.add_argument("--threshold", type=float, default=0.02)
        args = parser.parse_args()

        stats = ["pts","reb","ast","fg3m","stl","blk","tov"] if args.stat == "all" else [args.stat]
        results = [compare_models(s, args.threshold) for s in stats]

        failed = [r for r in results if r["status"] == "FAIL"]
        for r in failed:
            print(f"GATE FAIL: {r['stat']} delta={r['delta']:.4f} (threshold=-{args.threshold})")

        sys.exit(1 if failed else 0)
    ```
