    ```python
    """
    pod_manager.py — Autonomous RunPod lifecycle management for video ingest.

    Subcommands:
      launch   — Push ingest queue to pod, SSH in, start launch_single_3090_pod.sh
      status   — Print pod health (workers running, games done, GPU util)
      sync     — rsync tracking/events/DB from pod to local (safe to run mid-job)
      teardown — Run final sync then print manual stop reminder

    Config: reads RUNPOD_IP, RUNPOD_PORT, RUNPOD_USER from .runpod file (bash exports).
    Falls back to env vars if .runpod absent.

    Usage:
      python scripts/pod_manager.py launch [--dry-run]
      python scripts/pod_manager.py status
      python scripts/pod_manager.py sync [--dry-run]
      python scripts/pod_manager.py teardown [--dry-run]
    """
    ```

    **Config loading:**
    ```python
    _RUNPOD_FILE = ".runpod"

    def _load_config() -> dict:
        cfg: dict = {}
        if os.path.exists(_RUNPOD_FILE):
            for line in open(_RUNPOD_FILE):
                line = line.strip()
                if line.startswith("export "):
                    line = line[7:]
                if "=" in line:
                    k, v = line.split("=", 1)
                    cfg[k.strip()] = v.strip().strip('"').strip("'")
        # Env vars override file
        for key in ("RUNPOD_IP", "RUNPOD_PORT", "RUNPOD_USER"):
            if os.environ.get(key):
                cfg[key] = os.environ[key]
        return cfg
    ```

    **SSH/rsync helpers** (use subprocess.run, capture_output=False so output streams live):
    ```python
    def _ssh(cfg: dict, cmd: str, dry_run: bool = False) -> int:
        port = cfg.get("RUNPOD_PORT", "22")
        user = cfg.get("RUNPOD_USER", "root")
        ip = cfg["RUNPOD_IP"]
        full = ["ssh", "-o", "StrictHostKeyChecking=no", "-p", port, f"{user}@{ip}", cmd]
        if dry_run:
            print(f"[dry-run] ssh: {' '.join(full)}")
            return 0
        return subprocess.run(full).returncode

    def _rsync(cfg: dict, remote_path: str, local_path: str, dry_run: bool = False) -> int:
        port = cfg.get("RUNPOD_PORT", "22")
        user = cfg.get("RUNPOD_USER", "root")
        ip = cfg["RUNPOD_IP"]
        src = f"{user}@{ip}:{remote_path}"
        full = ["rsync", "-az", "--progress", "-e", f"ssh -o StrictHostKeyChecking=no -p {port}", src, local_path]
        if dry_run:
            print(f"[dry-run] rsync: {' '.join(full)}")
            return 0
        return subprocess.run(full).returncode
    ```

    Current exit block:
    ```bash
    if [ "$TOTAL_SYNCED" -ge "$TARGET" ]; then
    ```

    Replace with:
    ```bash
    # Check if orchestrator is still running on pod
    WORKERS=$($SSH "$REMOTE" "ps aux | grep season_100_orchestrator | grep -v grep | wc -l" 2>/dev/null || echo "0")

    if [ "$TOTAL_SYNCED" -ge "$TARGET" ]; then
      log "=== Target $TARGET games synced — done ==="
      break
    fi

    if [ "$WORKERS" -eq 0 ] && [ "$TOTAL_SYNCED" -gt 0 ]; then
      log "Orchestrator stopped. Running final sync..."
      # Pull remaining dirs not yet synced
      rsync -az -e "$SSH_CMD" "$REMOTE:$REMOTE_DIR/data/tracking/" "$LOCAL_DIR/" 2>/dev/null
    ```
