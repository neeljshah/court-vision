# Webapp performance and accessibility baseline -- 2026-10-20

> **Measured on the pre-restructure shell** (merge base 4df3555a1, before the 3f3e3cad3 restructure and the
> section lanes). Kept for the record; a fresh AFTER measurement on the restructured export is still owed
> before perf/budget.json and perf/a11y-pages.json gate CI.

Measured BEFORE any change on this branch, against the static export built exactly as
`.github/workflows/deploy-demo.yml` builds it (`npm ci`, `NEXT_PUBLIC_DATA_MODE=snapshot`,
`NEXT_PUBLIC_BASE_PATH=/court-vision`, `npm run build`, 3,451 HTML pages), served from `out/`
under `/court-vision/` by a local static server that gzips text assets the way GitHub Pages does.
The after-table for the same pages and method is `AFTER_2026-10-20.md`; the regression gate that
now runs in `webapp-qa.yml` is described in `README.md` in this directory.

Base commit: `4df3555` (master, 2026-10-20). Tooling: Lighthouse 12.8 (mobile preset = Moto G
Power emulation, 4x CPU slowdown, 1.6 Mbps simulated; desktop preset = no throttling), best of two
runs per page/preset by TBT; axe-core 4.10 via Playwright 1.56 on Chromium 141 at 1280x900 in both
themes (terminal `cv-theme`, analytics `cv-analytics-theme`); keyboard check = 25 Tab presses from
page load, counting stops whose computed `outline`/`box-shadow` show no focus ring.

## Where the bytes and the time go (baseline findings, in order of measured impact)

1. **`/analytics/papers/` document = 192 KB gzip (719 KB raw), of which 676 KB raw is React
   Server Component flight data.** `PapersIndex` is a client component and receives every
   paper's full body (sections, tables, figures) as props although a card prints seven fields.
   Mobile FCP 1.8 s / LCP 3.3 s on a page with no images is this payload.
2. **`/paper-trading/` CLS 0.398 mobile / 0.247 desktop** (the only page failing a Core Web
   Vital). Attribution (PerformanceObserver): the tally row above the equity panel appears after the
   baked JSON resolves and pushes the panel down 49 px, and the panel itself changes height when
   its loading skeleton (204 px chart placeholder, 32 px headline) is replaced by the real chart
   (174 px) and headline (36 px). TBT 120 ms on the same page is recharts hydrating (chunk
   `9410-*.js`, 373 KB raw / 106 KB gzip) -- the same chunk also ships on `/records`, `/today`,
   `/bets` and `/paper/<id>` because a 24 px sparkline imported it.
3. **Nav logo preload: `brand/icon-192.png` is 75 KB for a 24 px logo**, preloaded with
   `fetchPriority="high"` on every terminal page, so it competes with the render-blocking CSS
   (LH `uses-responsive-images` 71 KB, `modern-image-formats` 66 KB on 5 of the 10 pages).
   The 56 showcase chart PNGs (`public/img/showcase`, 5.2 MB) are RGBA at 1,950 px for a 1,072 px
   column; the module page's chart alone is 118 KB (`uses-responsive-images` 106 KB).
4. **Every analytics page loads cmdk + MiniSearch (~60 KB raw, chunk `2168-*.js`) for the
   command palette and every terminal page loads the Radix dialog + onboarding copy (~25 KB
   raw)** before a reader has asked for either.
5. **`three` is a dependency but is imported nowhere** (`npm ls` tree only; no bundle cost but
   an install cost and a false signal).
6. **Fonts**: the terminal uses the system stack (0 font bytes). The analytics root preloads four
   self-hosted woff2 files (114 KB: Fraunces variable with the `opsz` axis 66 KB, Libre Franklin
   29 KB, IBM Plex Mono 400/500 10 KB each), all `font-display: swap`, all used above the fold.
   CLS from the swap is 0 on every analytics page (next/font size-adjusted fallbacks), so fonts
   are left as they are.
7. **Accessibility (axe, serious): `/paper-trading/` 37 contrast nodes dark / 192 light, the
   paper trade detail 4 / 9, home 0 / 4, `/desk/` 0 / 2.** Root causes: hardcoded Tailwind palette
   utilities (`text-slate-500` 4.06:1 on the dark page, `text-slate-300/400` and `text-amber-400`
   1.3-2.5:1 on the light page) in the paper-trading panels; light-theme tokens `--primary`
   (3.55:1), `--warning` on its own 10% tint (4.07:1), `--faint` on that tint (4.07:1), `--success`
   on its 15% tint (3.74:1), `--danger` on its tint (4.41:1); dark `--danger` on its tint (4.31:1).
   Also serious: the two Radix scroll areas on `/paper-trading/` are not keyboard reachable
   (`scrollable-region-focusable`).
8. **Accessibility (moderate/minor)**: the demo banner sits outside every landmark on every
   terminal page (`region`); `/desk/` nests a second `<main>` inside AppShell's main
   (`landmark-no-duplicate-main`, `landmark-main-is-top-level`, `landmark-unique`) and has a blank
   column header in five tables (`empty-table-header`, LH `td-has-header`); the paper trade detail
   has no `<h1>`; LH `label-content-name-mismatch` on the analytics pitch-mix buttons (visible
   "FF 35.0%" vs `aria-label="Inspect Four-seam fastball"`), on the receipt triggers, and on the
   terminal nav logo link (visible "CourtVision multi-sport" vs `aria-label="CourtVision home"`).
9. **Motion**: analytics.css already collapses all animation under `prefers-reduced-motion`; the
   terminal's globals.css only froze the skeleton shimmer, leaving tailwindcss-animate dialog
   fades, pulses and colour transitions running.
10. **Keyboard**: the skip link is the first Tab stop on all 20 page/theme combinations and no
    tab stop in the first 25 lacks a visible focus ring, in either theme.

## What is fine already and left alone

- Desktop performance is 100 on 9 of 10 pages (87 on `/paper-trading/`, the CLS page).
- LCP element is text (the `<h1>`, or the demo banner on `/desk/`) on every page; no image LCP.
- No render-blocking third-party, no unminified assets, all static assets content-hashed.
- `uses-long-cache-ttl` fires on every page because GitHub Pages serves `max-age=600`; not
  controllable from the repo.
