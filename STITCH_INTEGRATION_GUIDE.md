# NBA AI System - Complete Stitch Integration Guide

## Overview
This guide shows how to connect your NBA AI system to Google Stitch for automatic deployment and updates.

## 🚀 Quick Start

### 1. Setup Environment
```bash
# Clone your repository
git clone <your-repo-url>
cd nba-ai-system

# Run setup script
chmod +x scripts/setup-stitch.sh
./scripts/setup-stitch.sh
```

### 2. Configure Environment Variables
Edit `.env` with your actual API keys:
```bash
# Required API Keys
NBA_API_KEY=your_nba_api_key_here
CLAUDE_API_KEY=your_claude_api_key_here  
THE_ODDS_API_KEY=your_the_odds_api_key_here

# Database (auto-generated by setup script)
DB_PASSWORD=your_secure_postgres_password
```

### 3. Deploy to Stitch
```bash
# Build and deploy
docker-compose build
docker-compose up -d

# Run database migrations
python scripts/migrate_db.py --migrate

# Seed initial data
python scripts/migrate_db.py --seed
```

## 🔧 Component Details

### 1. Docker Containers
- **API Server**: FastAPI with all ML models (`port 8000`)
- **PostgreSQL**: Database with all NBA data (`port 5432`)
- **Redis**: Caching and session storage (`port 6379`)
- **WebSocket**: Real-time updates (`port 8765`)
- **Streamlit**: Alternative dashboard (`port 8501`)
- **Nginx**: Reverse proxy (`ports 80/443`)

### 2. API Endpoints for Stitch
```
GET  /stitch/health              # Health check
GET  /stitch/dashboard/overview  # Main dashboard data
GET  /stitch/games/today         # Today's games
GET  /stitch/game/{game_id}      # Game details
GET  /stitch/player/{id}/props   # Player predictions
GET  /stitch/betting/edges       # Betting opportunities
WS   /ws/realtime               # WebSocket for live updates
```

### 3. Automatic Updates
- **Daily Pipeline**: Runs at 8 AM UTC via GitHub Actions
- **Model Retraining**: Triggered by `[retrain]` in commit message
- **Live Updates**: WebSocket pushes every 30 seconds
- **Database**: Auto-migrates on deployment

## 🔗 Connecting to Google Stitch

### Step 1: Create Stitch Project
1. Go to [Google Stitch](https://stitch.google.com)
2. Create new project: "NBA AI System"
3. Choose "Backend Integration" template

### Step 2: Configure Backend
In Stitch project settings:
```
Backend URL: https://your-domain.com/api
API Key: your_stitch_api_key
WebSocket URL: wss://your-domain.com/ws
Environment: Production
```

### Step 3: Frontend Integration
Use the Stitch prompt I provided earlier with these API calls:

```javascript
// Example API calls in Stitch
const API_BASE = 'https://your-domain.com/stitch';

// Get dashboard data
const dashboard = await fetch(`${API_BASE}/dashboard/overview`);

// Get live updates via WebSocket
const ws = new WebSocket('wss://your-domain.com/ws/realtime');
ws.subscribe('scores');
```
